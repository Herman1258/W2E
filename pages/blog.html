My Web Development Journey

Web development has been an incredibly eye-opening field. Learning how semantic structural tags like header, main, section, and article work helps search engines understand our content better. It also makes websites much more accessible for screen readers.

Setting up environments, working through the terminal, and managing folders can be tricky at first. Overcoming those early configuration roadblocks makes writing the actual code feel much more rewarding once everything connects properly.

Moving forward, my goal is to continue mastering structural design before jumping into advanced layouts and stylesheets. Building a solid semantic foundation ensures clean, maintainable code for future, larger applications.
